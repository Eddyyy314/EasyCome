# EASY COME V13 — COMPLETE PACKAGE

Questo pacchetto contiene tutto il materiale della versione Easy Come Hospitality V13 Autopilot.

## Struttura

- `source/` — progetto completo Easy Come con frontend, JavaScript, API/server handlers, SQL Supabase, configurazione Vercel, script di build e documentazione di release.
- `demo/index.html` — demo standalone V13 Autopilot corretta e apribile direttamente nel browser.
- `docs/PRODUCT-BLUEPRINT-V13.md` — blueprint prodotto e logica Autopilot / Pratica soggiorno.
- `backup/easycome-v5-original.zip` — copia del progetto originale fornito come base, mantenuta per sicurezza.

## Per vedere subito la demo

Aprire `demo/index.html` con Chrome, Edge, Safari o Firefox.

## Per lavorare sul progetto completo

Entrare nella cartella `source/`. Il progetto contiene il file `package.json`, `index.html`, le cartelle `js/`, `assets/`, `server/`, `api/`, gli script di build e i file SQL.

## Nota

La demo standalone è una dimostrazione del nuovo concept Autopilot. Le integrazioni reali con portali esterni, pagamenti, Alloggiati, ISTAT/Regioni, tassa di soggiorno e sistemi terzi richiedono credenziali/API e implementazione backend specifica.
