- Il loader di import non appare più prima dell'avvio reale.
- Selezionando uno ZIP valido l'import parte automaticamente; il pulsante resta disponibile come retry.
- Gli errori di upload/build restano visibili nel pannello invece di sembrare un caricamento infinito.
- Dopo l'import viene aperto il portale cliente Easy Come Web, non la sola preview grezza.
- Il portale cliente contiene anteprima live, prezzo, dati cliente e checkout Stripe.
- Il bottone footer, quando il sito è pronto, porta al portale/proposta cliente.
- Builder identificato come 39.0-static-handoff per diagnosi server più chiare.
